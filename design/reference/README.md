# Références design

Fichiers sources fournis pour la direction artistique. **Ne sont pas servis sur
le site** — ils servent uniquement de référence pour le développement.

- `homepage-maquette.webp` — la maquette officielle de la homepage TRENDS.
  C'est la référence à respecter pour la composition du hero.
- `logo-extrait.png` — le logo TRENDS® extrait de la maquette (basse résolution).
  À remplacer par le fichier logo officiel (SVG de préférence) dès que possible.

La photo du mannequin utilisée dans le hero (`public/brand/hero-model.webp`) a été
détourée à partir de cette maquette, en attendant une version officielle haute
résolution.
